# Sistema de Chamados de TI

Projeto de portfólio desenvolvido em Python e Flask para simular um sistema de abertura e gerenciamento de chamados de suporte técnico.

## Sobre o projeto

O sistema está sendo desenvolvido para praticar programação Python, desenvolvimento web, organização de aplicações e armazenamento de dados com SQLite.

## Funcionalidades

- Login com diferentes perfis de acesso
- Painel para usuários
- Painel para técnicos
- Formulário de abertura de chamados
- Seleção de prioridade
- Banco de dados SQLite
- Interface web com HTML e CSS

**Status:** Em desenvolvimento. Novas funcionalidades serão adicionadas progressivamente.

## Tecnologias utilizadas

- Python
- Flask
- SQLite
- HTML5
- CSS3
- Git e GitHub

## Como executar localmente

1. Instale o Python.
2. Clone este repositório para seu computador.
3. Instale o Flask executando:

   ```bash
   pip install flask
   ```

4. Entre na pasta do projeto e execute:

   ```bash
   python app/app.py
   ```

5. Abra no navegador:

   `http://127.0.0.1:5000/login`
